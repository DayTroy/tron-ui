# Tron UI
<img width="1512" height="793" alt="Tron-Preview" src="https://github.com/user-attachments/assets/beaa43d9-8720-42f3-9f8e-36849a8c4d11" />

Angular 19 component library. Dark grid, neon chrome.

The catalog is the documentation: every component is on a page.

```bash
npm install
npx ng serve
```

Open [http://localhost:4200/](http://localhost:4200/).

Library lives in `projects/tron-ui`. Tokens and theme are in `projects/tron-ui/styles`.
